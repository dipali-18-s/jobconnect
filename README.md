# 💼 JobConnect – Online Job Portal System

JobConnect is a full-stack web application developed to bridge the gap between job seekers and recruiters. The platform enables students to search and apply for jobs, recruiters to post and manage job openings, and administrators to oversee the entire system through a centralized dashboard.

## 🚀 Features

### 👨‍🎓 Student Module

* Student Registration & Login
* Create and Update Profile
* Browse Available Jobs
* Search Jobs
* Apply for Jobs
* Upload Resume
* View Applied Jobs
* Track Application Status

### 🏢 Recruiter Module

* Recruiter Registration & Login
* Manage Company Profile
* Post New Jobs
* Edit & Delete Job Listings
* View Applicants
* Update Application Status

### 👨‍💼 Admin Module

* Secure Admin Login
* Dashboard Overview
* Manage Students
* Manage Recruiters
* Manage Jobs
* Manage Applications
* System Monitoring

## ⚙️ Installation

1. Install **XAMPP**.
2. Copy the project folder into the **htdocs** directory.
3. Start **Apache** and **MySQL** from the XAMPP Control Panel.
4. Open **phpMyAdmin** and create a database named **`jobconnect`**.
5. Import the **`jobconnect.sql`** file into the database.
6. Update the database connection settings in **`includes/db.php`** if required.
7. Open your browser and visit:

```text
http://localhost/JobConnect/
```
